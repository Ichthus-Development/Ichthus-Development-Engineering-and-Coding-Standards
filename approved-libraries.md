# Approved Libraries and Dependencies

> **Policy status:** Governance framework. No dependency is approved merely by appearing in a project or by this document's existence.

Third-party dependencies should be evaluated for necessity, maintenance health, licensing, security, privacy, transitive dependencies, interoperability, and exit cost.

Future approvals should record the canonical package, ecosystem, approved use, status, version policy, license, security posture, rationale, alternatives, review date, and responsible owner.

Recommended statuses are **Approved**, **Conditional**, **Legacy**, and **Prohibited**. Adding an entry or changing its status must be intentional, reviewed, and supported by rationale.
